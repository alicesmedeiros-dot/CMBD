 ** Projeo Banco de Dados Sistema de Vendas **

 Este projeto foi desenvolvido para a criação de um banco de dados relacional 
 aplicado a um Sistema de Vendas.

 A primeira parte do projeto contém a representação do modelo do DB através de 
 um diagrama de entidade-relacionamento.

 Criação das Tabelas:
  - Clientes;
  - Produtos;
  - Pedidos;
  - Fornecedores;
  - Compras.

  O rpojeto possui com código de fonte revisado e documentado.
